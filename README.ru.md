## 🌟 О программе

**galIMVmini** — это минималистичное и отзывчивое приложение для Windows, созданное специально для просмотра сгенерированных изображений и детального анализа метаданных генерации. Программа воплощает визуальный стиль и возможности парсинга **galIMV**, но в компактном, лёгком формате без избыточных модулей.

---

## ✨ Ключевые возможности

### 🔍 Глубокий парсинг AI-метаданных
- **Stable Diffusion (Automatic1111, WebUI Forge, SD.Next)**: автоматическое извлечение позитивного и негативного промптов, чекпоинта модели, хэша, сэмплера, шагов, CFG scale, сида, силы денойза и clip skip.
- **WebUI Forge / TIPO / ADetailer**: структурированное распознавание расширенных параметров и моделей детекторов в виде аккуратных бейджей.
- **ComfyUI**: рекурсивный обход нодового графа (`KSampler`, `CLIPTextEncode`, `CheckpointLoaderSimple`, скрытые размеры, апскейлеры).
- **NovelAI и Fooocus**: извлечение встроенных JSON метаданных.
- **Midjourney и EXIF**: извлечение параметров камеры, разрешения, мегапикселей, цветового профиля и времени создания.
- **Сайдкар файлы (`.txt`)**: автоматическое чтение текстовых описаний рядом с файлом; блок сайдкара скрывается, если файл отсутствует, не загромождая интерфейс.

### 📐 Анализ соотношения сторон (Aspect Ratio)
- Точный автоматический расчет соотношения сторон с определением стандартных форматов:
  - `1:1`, `16:9`, `9:16`, `4:3`, `3:4`, `3:2`, `2:3`, `21:9`, `5:4`, `7:4 (~16:9)`
- Отображение соотношения в бейдже параметров промпта, заголовке окна и строке состояния.

### 🎨 Дизайн-система galIMV (Lobe Hub Neo)
- **100% векторные иконки Tabler**: чистые четкие иконки для любых экранов и DPI без использования смайликов/эмодзи.
- **Иконка реального размера и соотношения**: векторная иконка Tabler `aspect-ratio` для сброса на 100% натуральный масштаб.
- **Сохранение настроек**: тема (светлая/тёмная), выбранный акцент и язык автоматически сохраняются в конфигурации и восстанавливаются при перезапуске.
- **6 акцентных цветов Lobe**: Синий (`#1677ff`), Фиолетовый (`#722ed1`), Изумрудный (`#10b981`), Оранжевый (`#fa8c16`), Розовый (`#f43f5e`), Цинк (`#71717a`).
- **Баланс 50 / 50**: пропорция по умолчанию пополам между просмотром изображения и инспектором метаданных с возможностью удобного изменения сплиттером.
- **Компактная верхняя панель**: аккуратные кнопки в стиле оригинального galIMV.

### 🖥️ Полноэкранный режим и производительность
- **Полноэкранный просмотр**: горячая клавиша `F11`, выход по нажатию `Esc`.
- **Компактный полноэкранный интерфейс**: поля промптов, карточки и вкладки сохраняют компактные границы без раздутых пустых отступов при максимизации окна.
- **Автоматическая подгонка холста**: плавное масштабирование и центрирование изображения при входе и выходе из полноэкранного режима.
- **Высокая отзывчивость**: умная перерисовка вьюпорта (`SmartViewportUpdate`), кэширование расчета ширины текста и пакетное обновление таблиц.

## ⌨️ Горячие клавиши

| Сочетание | Действие |
| :--- | :--- |
| **Ctrl + O** | Открыть файл изображения |
| **Ctrl + H** | История недавно открытых файлов |
| **Ctrl + C** | Скопировать промпт в буфер обмена |
| **Ctrl + E** | Экспортировать метаданные (TXT, Markdown, JSON, CSV) |
| **0** | Вписать изображение в окно |
| **1** | Реальный размер 100% |
| **+** / **-** | Увеличить / Уменьшить масштаб |
| **Колесо мыши** | Плавный зум в точку под курсором |
| **Зажатие ЛКМ** | Панорамирование изображения (Drag & Drop) |
| **I** | Скрыть / показать панель инспектора |
| **F11** | Полноэкранный режим |
| **Esc** | Выход из полноэкранного режима |

## 🚀 Запуск из исходного кода

### Требования
- Python 3.8 или новее
- Windows 10 / 11 (или Linux / macOS с PyQt6)

### Установка зависимостей
```bash
git clone https://github.com/your-username/galIMVmini.git
cd galIMVmini
pip install -r requirements.txt
```

### Запуск
```bash
python main.py
```
*Либо запустите файл `run.bat` на Windows.*

## 📦 Сборка автономного EXE (Windows)

Для сборки автономного исполняемого файла без необходимости установки Python используется PyInstaller:

```bash
# Сборка быстрой портативной папки
python build_exe.py

# Сборка единого переносимого EXE файла
python build_exe.py --onefile
```

*Либо дважды кликните `build_exe.bat`.* Готовый исполняемый файл появится в папке `dist/`.

## 📂 Структура проекта

```
galIMVmini/
├── core/
│   ├── i18n.py          # Движок интернационализации (20 языков)

├── build_exe.py         # Скрипт сборки PyInstaller
```
