# Общий интерфейс galIMV и galIMVmini

Этот справочник предназначен для разработчика двух просмотрщиков: он описывает, где менять общие иконки и размеры, как синхронизировать их и проверить результат.

## Общий каталог

Исходный каталог — `galIMV/resources/ui/design.json`. Он содержит 55 имён SVG Tabler, 12 акцентов Lobe из GestArt, цвета светлой и тёмной тем, шрифты и размеры контролов. Координаты иконок используют `viewBox="0 0 24 24"`, толщину линии 2 и круглые окончания. Псевдонимы существующих имён сохранены.

galIMV получает каталог через `qml/DesignSystem.js`. galIMVmini читает идентичный JSON из своего `resources/ui/design.json` через `core/design.py`. Модуль `core/icons.py` создаёт изображения с масштабами 1×, 2× и 3×.

После изменения JSON выполните из папки galIMV следующую команду:

```powershell
python scripts/sync_viewer_design.py --mini-root ../galIMVmini
```

Она обновляет QML-модуль и копию каталога mini. Затем пересоберите оба приложения. Проверка `galIMVmini/tests/test_ui_unification.py` сравнивает содержимое двух JSON и QML-модуля и проверяет отрисовку всех иконок.

Подписи и подсказки описывают действие. Кнопки имеют имя для средств доступности и видимый клавиатурный фокус. Текст на акцентных кнопках выбирается по контрасту светлого и тёмного вариантов; проверка покрывает все 12 акцентов в обеих темах. При необходимости используется чёрный текст для контраста не ниже 4,5:1. В mini подложка выбранного элемента использует активный цвет вместо постоянного синего.

## Различие поверхностей

galIMV использует стеклянные панели с размытием фоновой сцены Aurora, регулируемым оттенком и насыщенностью. `qml/FrostedPanel.qml` захватывает только фон, поэтому текст и содержимое переднего плана сохраняют резкость. При программном рендеринге используется почти непрозрачная подложка: этот режим не поддерживает аппаратные шейдеры. Прозрачность, размытие, оттенок и насыщенность сохраняются между запусками.

`qml/SurfaceSheen.qml` задаёт общий верхний блик: контур следует верхней грани и обеим дугам скругления до боковых краёв. Обрезка по верхней части настоящего скруглённого контура сохраняет границы без горизонтальных отступов, в том числе у узких элементов. Текстовые поля и блоки промптов используют непрозрачную подложку для читаемости. galIMVmini использует непрозрачные поверхности без размытия и бликов стекла.

## Палитра GestArt Lobe

Палитра содержит Red, Orange, Gold, Yellow, Lime, Green, Cyan, Blue, Geek blue, Purple, Magenta и Volcano. Значения `hex`, `light` и `dark` перенесены из `GestArt Ultimate/assets/themes.json`, раздел `lobe`, без изменения. В светлой и тёмной теме применяются соответствующие варианты. Имена имеют вид `Lobe Red`, `Lobe Orange` и т. д. Прежние семь вариантов удалены из каталога и меню. Сохранённые имена с префиксом GestArt автоматически преобразуются в Lobe; удалённый Monochrome Zinc заменяется на Lobe Blue. В mini все поверхности остаются непрозрачными.

## Поведение mini

До открытия изображения инспектор объясняет своё назначение; масштабирование и экспорт недоступны. На пустом холсте есть обычная кнопка открытия, доступная с клавиатуры. Ошибка чтения нового файла сохраняет прежнее изображение и метаданные.

При ширине окна менее 1080 px второстепенные кнопки панели показывают только иконки с подсказками. При ширине карточек параметров менее 460 px параметры переходят в одну колонку. Заголовки сокращаются с сохранением полного текста в подсказке. Размер и видимость инспектора сохраняются.

Один таймер управляет сообщениями состояния: сообщение от предыдущего действия не очищает более новое. После временного сообщения строка состояния возвращается к сведениям о текущем файле.

## Проверка

Запустите существующие CTest-наборы galIMV и `python tests/test_ui_unification.py` из папки galIMVmini. Дополнительно проверьте обычное и узкое окно в светлой и тёмной темах, открытие изображения, копирование промптов и восстановление прежнего изображения после ошибки чтения нового файла.

Автоматические сценарии не заменяют ручную проверку с Windows Narrator и физическим управлением на каждой целевой ОС.

## Общее название

Левый верхний угол использует контурный знак изображения и надпись galIMV: gal окрашен читаемым акцентом с обычным начертанием, IMV использует жирное начертание и основной цвет текста. В mini справа добавлена небольшая контурная метка mini. Геометрия знака, шрифт и интервалы определены общим разделом brand в resources/ui/design.json. Акцент адаптируется для контраста текста не ниже 4,5:1. Знак и метка не являются кнопками.

## Иконки и подтоны

Иконка окна и панели задач выбирается из resources/accent-icons по текущему акценту. Все 12 вариантов содержат размеры 16–256 px; геометрия исходной иконки сохраняется. galIMV использует стеклянный рисунок, mini — непрозрачный. Цвет меняется сразу при выборе акцента.

В galIMV восемь пар нейтральных материалов связывают тёмную и светлую темы: цинк/мягкий цинк, уголь/выцветшая бумага, графит/матовый мел, сланец/алебастр, базальт/светлый камень, обсидиан/фарфор, тёплый камень/слоновая кость и чистый чёрный/белый. Выбор материала сохраняется между темами; яркость задаётся отдельно. Точные цвета хранятся в UI.neutralTones. Для чёрного/белого ползунок отключён. Светлая Aurora остаётся насыщенной и видимой.


## Проверка локализации

Каждый из 20 JSON-словарей в locales должен содержать тот же набор ключей, что и en_US.json. Сохраняйте параметры %1, %2 и {count}; имена файлов, моделей и значения метаданных берутся из исходного файла. В mini выбранный JSON имеет приоритет перед словарём совместимости MINI_FALLBACKS.

Проверка обоих наборов словарей и переключения интерфейса mini: `python tests/test_translations.py` из каталога galIMVmini. CTest в galIMV проверяет все 20 языков, обновление QML, сообщения файловых операций и ошибки словаря тегов.
